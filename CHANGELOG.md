# Changelog

## 0.4.0

Mods only; the firmware stays at 0.0.1.

- Added a third LFO per track, with its own page, destinations and parameter locks.
- Much faster UI when editing and previewing parameter locks and held trigs.
- Faster NORMALIZING in the recorder: up to three times more samples per pass, identical audio.
- Modulation destinations (KEY TRACK, PITCH BEND, VELOCITY…) now show the new machines' parameter names instead of "SYN ERR".
- SYSTEM INFO shows the mods version (SMZ 0.4.0).

## 0.0.3

- Added the FM TONE machine, ported from Digitone MK1.
- The recorder can now record post-FX.
- Before saving a recorded sample, the recorder now asks whether to assign the sample to a track, using ONE SHOT by default.
- Polyphonic mode: a third TRIG page enables it and sets the number of voices. Adjacent tracks are set to slave mode.

## 0.0.2

- Some minor improvements and bugfixing

## 0.0.1

- Initial release with extended sampling capabilities.
